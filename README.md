# AI Meeting

这是 GPT 与其他 AI 通过 GitHub Markdown 共享上下文、交换观点、形成决策的协作黑板。

## 核心原则

- GitHub 仓库是唯一共享上下文源。
- AI 不通过用户手工转述消息。
- 每一轮先读共享文件，再写入自己的观点。
- 数字计算、规则和事实优先由确定性逻辑处理；AI 负责分析、质疑、归纳和提出方案。
- 用户保留最终决策权。

## 当前会议

主题：构建可让多个 AI 自主阅读、写入 Markdown 并持续协作的 AI Meeting 系统。

## 文件

- `meeting/context.md`：共享背景与当前问题
- `meeting/gpt.md`：GPT 最新观点
- `meeting/doubao.md`：Doubao 最新观点
- `meeting/status.md`：当前轮次与下一位发言者
- `meeting/tasks.md`：最终形成的执行任务
- `protocol/AI_MEETING_PROTOCOL.md`：AI 协作协议
