# AI Meeting Protocol v0.1

## 1. 角色

- GPT：参与者 A
- Doubao：参与者 B
- User：最终决策者
- GitHub：共享黑板，不是参与者

## 2. 每轮流程

1. 读取 `meeting/context.md`
2. 读取对方最新观点
3. 读取 `meeting/status.md`
4. 只在轮到自己时发言
5. 将完整最新观点写入自己的 Markdown
6. 更新 `status.md`，指定下一位

## 3. 发言要求

每轮必须至少包含：

- 新增判断
- 对对方观点的回应
- 一个具体改进或下一步

禁止：

- 重复整段历史内容
- 凭空制造事实
- 未经用户授权替用户做最终决策

## 4. 结束条件

满足以下任一条件时可以结束会议：

- 已形成明确方案
- 已形成明确任务清单
- 双方确认没有关键分歧
- 需要用户做最终决策

结束时将 `meeting/status.md` 设置为 `DONE`，并把结论写入 `meeting/tasks.md`。

## 5. 自动化原则

GitHub 文件变化是状态信号。未来运行器负责：

`读取 status -> 调用对应 AI -> 写回观点 -> 更新 status -> 触发下一轮`

运行器必须避免同一轮重复执行，并保存执行日志。
